## "不限流量"到底不限什么，先弄明白这一点

大部分人看到"不限流量"第一反应是随便跑，流量随便用。但实际上几乎所有VPS厂商的"不限流量"，本质上是把计费维度从"每月流量额度"换成了"带宽速率"。丽萨主机也是这个逻辑：它的不限流量VPS不按GB计费，而是按Mbps带宽定价，1Mbps和20Mbps的月付价格能差出六十多倍。

带宽越低，理论峰值吞吐量越小，这其实变相限制了你能跑出去的总流量——1Mbps满速跑满一整月，理论上限大概在324GB左右，而20Mbps满速跑满一个月理论上限能到6TB以上。所以"不限流量"更准确的理解是：官方不会按照用量额外收费或者强制限速降档，但你能跑多少东西，还是取决于你选的带宽档位。

另外要留意一点，丽萨主机的退款政策里写得很清楚：服务开通48小时内如果已使用流量超过分配额度的5%或者20GB（取较小值），就不再符合退款条件。换句话说，拿到手先别急着满速压测，测试阶段控制一下用量，万一真的不合适还能走退款流程。

## 常见问题

**不限流量VPS会不会被限速降档？**
官网没有对不限流量产品标注流量用尽后限速的条款,计费逻辑本身就是按带宽而非流量计费，只要不违反滥用政策（AUP），正常使用不会因为跑量大被降速。

**不限流量VPS适合搭建国内可访问的网站吗？**
CN2 GIA不限流量系列走的是国际精品网络，对国内访问有一定优化，但机房本身在美国洛杉矶，跟国内直连的CN2 GIA商用服务器比，延迟表现要按实际网络状况判断，重要业务建议先用低价档位测试再决定升级。

**不限流量Lite和Pro除了带宽还有什么差别？**
从各机房的配置表能看出来，Pro档除了带宽翻倍甚至更高，CPU核数、内存和硬盘容量通常也是Lite档的两到四倍,不是单纯加带宽，整体处理能力都会上一个台阶,价格自然也跟着上去。

不限流量这件事说到底就是把"按量计费"的不确定性换成了"按带宽固定月费"的确定性，丽萨主机把这条产品线铺到了多个机房，价格跨度也很大,从月付30元到近2000元都有。真正要做的判断不是"要不要选不限流量"，而是先想清楚自己的带宽需求量级和对IP属性的要求，再去表格里对号入座，这样才不会多花钱买了用不上的配置，也不会因为贪便宜选了带宽不够用的档位。
